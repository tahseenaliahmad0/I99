# Review reports

What the adversarial reviews of M6, M7, M8 and M10 found, as their agents
returned it: one finding each with the GDD sentence, the evidence, what a
player meets and a proposed fix. `m8_verify_*` are a second agent's verdicts
on the M8 findings (where it corrects the reviewer, the verifier is right).

The rulings on these findings are in `docs/DECISIONS.md` (D-049 and D-055
for M6, D-057 and D-058 for M7, D-059 for M8, the addenda of D-052 to D-054
for M10). What is still open is listed in `docs/PROGRESS.md`.

The probes and pictures the reports name lay in a scratch folder that did
not outlive its session: a finding that is taken up again must be
reproduced again.
